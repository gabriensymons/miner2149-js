# Idea Template

```markdown
title: <Idea title>
date: <YYYY-MM-DD>
source: <codex|claude|user|other>
status: <idea|draft|explore>
owner: <person>

## Context
What problem or opportunity this idea addresses.

## Idea
Core concept in plain language.

## Next Steps
What to validate, prototype, or decide next.
```

## Notes
- Default save location is `.agents/ideas/`.
- Filename format is `YYYY-MM-DD-<slug>.md`.

- Reuse an established project destination instead of creating a competing directory.
- The helper adds metadata; pass only the body when using it.
